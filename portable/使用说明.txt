影策 Windows 便携版（绿色免安装）
========================================
打包：Passwd Word（源码：ddcat-ai/open-ai-canvas）


1. 解压到任意目录（建议 D:\yingce，路径避免中文和空格）。
2. 双击「启动影策.bat」，等待浏览器自动打开 http://127.0.0.1:18789
3. 首次使用：注册管理员账号（仅本机可注册）。
4. 左下角设置 → 模型渠道：填入你的 AI 模型 API 地址和 Key 才能生成。
5. 彻底退出：运行「停止影策.bat」（直接关启动窗口不会停服务）。


- yingce.exe：后端（含 SQLite 数据库、任务队列）+ 前端页面已打包进
同一个 exe，双击启动脚本即可用，无需安装 Node/Python/数据库。
- tools\node：内置 Node.js（供画布 Agent 调用）。
- tools\ffmpeg：内置 ffmpeg（供视频转码、字幕转写）。
- agent-runtime：画布 Agent 运行环境。
- plugin-packages：官方模型/支付插件包。
- data\：你的全部数据（账号、画布、素材、任务记录）。备份只拷这个目录。


- 首次启动 Windows 防火墙可能弹窗，选"允许"（仅监听本机 127.0.0.1）。
- 杀毒软件若误报，把解压目录加入白名单即可（exe 为本机编译，无加壳）。
- 换电脑：整个目录拷走，data 也跟着走，开箱即用。
- 端口 18789 如被占用，改「启动影策.ps1」里的 $port 即可。
